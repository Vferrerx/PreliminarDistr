Origem e transportadora (rota → CD)

O CD de origem e a transportadora de cada rota vêm exclusivamente da tabela de referência abaixo (prefixo alfabético da rota — ex: BA460M → prefixo BA). O sistema não lê mais o campo "Transportadora" do PDF para isso. A transportadora é usada apenas para decidir quais rotas são elegíveis à criação automática de linha de retorno ao CD.

Tabela de referência: Prefixo × CD × Transportadora

Não é editável por aqui — para atualizar, substitua o conteúdo de data/prefixo_cd_transportadora.js por uma nova planilha com as mesmas 3 colunas.

Limitações conhecidas

  • Data e hora de carregamento: vêm exclusivamente da linha "Carregamento: <dia> HH:MM" de cada bloco do PDF — o dia (2.F a 6.F, Sáb, Dom) é convertido para a data real a partir da Data de Faturamento impressa no topo do documento. Nenhuma outra fonte (histórico, planilha antiga) é usada para esse campo.
  • Retorno automático ao CD: só é criado para rotas cuja transportadora (tabela acima) seja elegível e que já possuam evidência histórica de retorno. Rotas novas, ainda sem histórico, não recebem retorno automático — adicione a linha manualmente se necessário.

Processamento 100% local no navegador nenhum arquivo é enviado a servidores externos.
