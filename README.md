# 📊 Prog Generator (Automação de Base de Monitoramento)

Prog Generator é uma ferramenta de automação focada em produtividade logística. 

O sistema extrai dados não-estruturados de arquivos PDF e os converte, de forma automatizada, em bases de monitoramento no formato Excel (.xlsx). Ideal para reduzir trabalho manual e acelerar a análise de dados logísticos.
